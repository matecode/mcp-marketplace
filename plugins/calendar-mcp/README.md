# Kalender MCP

Kalender und Kontakte über das persönliche Mailbox.org-Konto.

Adresse: `https://mcp.bunteban.de/calendar/mcp`.

Nach Installation persönlich über OAuth/Authentik anmelden. Repository-Zugriff erteilt keine Dienstfreigabe. Keine Tokens oder Passwörter in Paketdateien eintragen.

Einrichtung und Prüfgrenzen: [Marketplace-Anleitung](../../README.md).

Claude Code: `/plugin install calendar-mcp --marketplace matecode/mcp-marketplace`

Codex: `codex plugin add calendar-mcp@mate-mcp` (Marketplace vorher registrieren).
