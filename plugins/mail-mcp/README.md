# Mail MCP

Mail und Sieve über das persönliche Mailbox.org-Konto.

Adresse: `https://mcp.bunteban.de/mail/mcp`.

Nach Installation persönlich über OAuth/Authentik anmelden. Repository-Zugriff erteilt keine Dienstfreigabe. Keine Tokens oder Passwörter in Paketdateien eintragen.

Einrichtung und Prüfgrenzen: [Marketplace-Anleitung](../../README.md).

Claude Code: `/plugin install mail-mcp --marketplace matecode/mcp-marketplace`

Codex: `codex plugin add mail-mcp@mate-mcp` (Marketplace vorher registrieren).
