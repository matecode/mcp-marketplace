# LiZu MCP

Nextcloud-Werkzeuge mit persönlicher Kontozuordnung.

Adresse: `https://mcp.bunteban.de/lizu/mcp`.

Nach Installation persönlich über OAuth/Authentik anmelden. Repository-Zugriff erteilt keine Dienstfreigabe. Keine Tokens oder Passwörter in Paketdateien eintragen.

Einrichtung und Prüfgrenzen: [Marketplace-Anleitung](../../README.md).

Claude Code: `/plugin install lizu-mcp --marketplace matecode/mcp-marketplace`

Codex: `codex plugin add lizu-mcp@mate-mcp` (Marketplace vorher registrieren).
