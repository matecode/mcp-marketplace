# Kleinanzeigen MCP

Kleinanzeigen-Werkzeuge des bestehenden Homelab-Dienstes.

Adresse: `https://mcp.bunteban.de/kleinanzeigen/mcp`.

Nach Installation persönlich über OAuth/Authentik anmelden. Repository-Zugriff erteilt keine Dienstfreigabe. Keine Tokens oder Passwörter in Paketdateien eintragen.

Einrichtung und Prüfgrenzen: [Marketplace-Anleitung](../../README.md).

Claude Code: `/plugin install kleinanzeigen-mcp --marketplace matecode/mcp-marketplace`

Codex: `codex plugin add kleinanzeigen-mcp@mate-mcp` (Marketplace vorher registrieren).
