# Obsidian MCP

Notizen im freigegebenen Obsidian-Vault lesen und bearbeiten.

Adresse: `https://mcp.bunteban.de/obsidian/mcp`.

Nach Installation persönlich über OAuth/Authentik anmelden. Repository-Zugriff erteilt keine Dienstfreigabe. Keine Tokens oder Passwörter in Paketdateien eintragen.

Obsidian ist an den freigegebenen Betreiber-Vault gebunden; andere GitHub-Nutzer erhalten dadurch keinen eigenen Vault. Die Gesprächsablage-Regel bleibt ausschließlich über die MCP-Server-Instructions und die zentrale Vault-Notiz bereitgestellt.

Einrichtung und Prüfgrenzen: [Marketplace-Anleitung](../../README.md).

Claude Code: `/plugin install obsidian-mcp --marketplace matecode/mcp-marketplace`

Codex: `codex plugin add obsidian-mcp@mate-mcp` (Marketplace vorher registrieren).
